# PEKA v0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship PEKA v0.1.0, a Claude Code plugin that gives Claude global memory and background learning from experience.

**Architecture:** Hook scripts (one Node entrypoint) keep per-session counters and trigger a background `peka:reviewer` subagent through Stop-hook context; a weekly `peka:curator` subagent maintains the library. All data lives in `~/.peka`, skills are exposed via symlinks in `~/.claude/skills`.

**Tech Stack:** Node ≥ 18 ESM (`.mjs`), zero dependencies, `node:test` for tests, git CLI (optional).

**Spec:** `docs/specs/2026-10-11-peka-design.md`

## Global Constraints

- Zero npm dependencies; only Node built-ins. Node ≥ 18.
- Every hook exits 0 and never prints non-JSON to stdout; errors go to `state/peka.log`.
- No network calls, no `claude -p`, no Agent SDK.
- Tests isolate the filesystem with `PEKA_HOME` and `CLAUDE_CONFIG_DIR` pointing into `fs.mkdtempSync` dirs.
- Text never mentions any other agent product; all prompt text is original.
- Commits carry no AI attribution trailers.
- Heavy commands (`npm test`) run one at a time.

## Review Focus

1. A hook receiving empty/garbage stdin must exit 0 with no output → test in Task 6.
2. A write path like `~/.peka/memory/../../.bashrc` or a symlink inside `~/.peka` pointing out must not be auto-allowed → Task 3.
3. An existing non-PEKA `~/.claude/skills/<name>` must never be replaced or removed → Task 4.
4. A settings.json that is not valid JSON must not be overwritten → Task 5.
5. Stop must not fire twice for one checkpoint (stop_hook_active, in-flight reviewer) → Task 6.

### Task 3: Write/read guard

**Files:** `scripts/lib/guard.mjs`, `test/guard.test.mjs`

**Produces:** `classify(toolName, toolInput, d, claudeSkillsDir) → {decision: "allow"|"deny"|null, reason?: string, kind?: "memory"|"skill"|"state"}`
- Path field: `file_path` (Write/Edit/Read) or `path` (Glob/Grep; missing → null).
- Resolve: expand `~`, `path.resolve`, then realpath of nearest existing ancestor + remaining segments.
- Allow: `.md` under `memory/` or `skills/` for all five tools; any read tool (Read/Glob/Grep) under `state/`; Write/Edit exactly `state/curator-actions.json`.
- Deny: Write/Edit whose unresolved path is under `claudeSkillsDir/<name>/` where `<name>` is a symlink resolving into `skills/`; reason contains the real path.

- [ ] Tests: allow memory md, allow skill md, no-allow skill `.sh`, no-allow `memory/../../x.md`, no-allow when `skills/evil` is a symlink to outside, deny write via `~/.claude/skills/<name>` link with real path in reason, allow Grep `path` under state, null for unrelated paths.
- [ ] Implement, pass, commit `feat: path guard for PEKA-owned files`.

### Task 4: Skill library

**Files:** `scripts/lib/skills.mjs`, `test/skills.test.mjs`

**Produces:**
- `listSkills(d): string[]` — dirs in `skills/` containing `SKILL.md`, sorted.
- `syncLinks(d, claudeSkillsDir) → {created: string[], removed: string[], conflicts: string[]}` — create `claudeSkillsDir/<name>` → `skills/<name>` (`fs.symlinkSync(target, link, "junction")`); remove links in `claudeSkillsDir` whose target is inside `skills/` or `archive/` but no longer a live skill; never touch non-PEKA entries.
- `recordUse(usage, name, nowIso)` — increments `uses`, sets `lastUsed`, `state: "active"`.
- `applyLifecycle(d, usage, now: Date, cfg) → {stale, archived, reactivated}` — anchor = `lastUsed ?? created`; unseen skill gets `created = now` and is skipped; pinned skipped; ≥ `archiveAfterDays` → `archiveSkill`; ≥ `staleAfterDays` → `state: "stale"`; else active (stale→active counts as reactivated).
- `archiveSkill(d, name, now) → string` — move to `archive/skills/<name>` or `<name>-<YYYYMMDDHHmmss>` if taken; set usage state `"archived"`.

- [ ] Tests: sync creates link, idempotent second run, conflict on existing real dir left untouched, dangling PEKA link removed, lifecycle seeds then stales at 14d, archives at 30d, pinned never archived, archived skill's link removed by next sync.
- [ ] Implement, pass, commit `feat: skill library with links and lifecycle`.
